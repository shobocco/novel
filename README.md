# 残クレバハムートで魔王討伐

## 1. プロジェクト概要

「残クレバハムートで魔王討伐」は、剣と魔法のファンタジー世界を舞台としたノベルゲーム。

主人公は冒険者として魔物を討伐して生活していたが、ある日「神様」に魔王討伐の使命を与えられる。

神様から与えられた切り札は、人語を解する最強クラスの黒竜「バハムート」。

しかしバハムートは無償で与えられたものではなく、価値10億ゴールドのバハムートを「残価クレジット」で契約するというものだった。

主人公は、

**魔物を討伐 → 冒険者ギルドから報酬を獲得 → バハムートのローンを返済**

という生活を繰り返しながら、バハムートとともに魔王討伐を目指す。

しかし魔王との対面によって、主人公は「神様に詐欺まがいの契約を結ばされている」という事実を知る。

最終的にプレイヤーの選択によって、

- 魔王を倒す
- 魔王と共闘して神様を倒す

というルートへ分岐する。


# 2. ゲームジャンル

基本ジャンル：

**ファンタジー・コメディ系ノベルゲーム**

ノベルゲームをベースとして、以下の簡易ゲームシステムを組み合わせる。

- シナリオ進行
- 選択肢
- 魔物討伐
- 討伐報酬
- 所持金管理
- ローン返済
- バハムートの価値管理
- ルート分岐
- マルチエンディング


# 3. 作品の方向性

世界そのものは王道の「剣と魔法のファンタジー」。

一方で、

- 残価クレジット
- ローン
- 月々の支払い
- 査定
- 残債
- 支払い不能

など、現代的な金融用語が当然のようにファンタジー世界へ入り込んでいることをギャグとして扱う。

序盤では、

**神様＝善  
魔王＝悪**

という一般的なファンタジー作品の構図に見せる。

ストーリーが進むにつれて、

**神様＝主人公を暇つぶしに利用している悪者  
魔王＝主人公が騙されていることを教えてくれる人物**

という構図へ逆転させる。


# 4. 主要キャラクター

## 主人公

一般的な若い男性冒険者。

モンスター討伐の報酬で日々生活している。

神様から使命を与えられ、魔王討伐へ向かう。

基本的には常識人。

神様、魔王、バハムートなど癖の強いキャラクターに対するツッコミ役でもある。


## バハムート

人語を理解し、会話することのできる巨大な黒竜。

非常に強力。

設定上の価値は、

**10億ゴールド**

主人公が神様から残価クレジット契約によって借りている。

単なる戦闘用モンスターではなく、主人公の旅の相棒として扱う。


## 神様

美しく慈愛に満ちた外見の女神。

主人公へ魔王討伐の使命を与える。

しかし本性は悪者。

暇つぶしで魔王討伐を思いつき、主人公にバハムートの莫大な負債を押し付け、その様子を楽しんでいる。

序盤では善良な神様として振る舞い、徐々に腹黒さを見せる。


## 魔王

魔王城を支配している人物。

物語序盤では主人公が倒すべきラスボスとして扱われる。

しかし主人公が神様と結んだバハムートの契約内容を知り、

「それは詐欺ではないのか？」

と主人公へ指摘する。

主人公に神様の真実を伝え、自分と組んで神様を倒すことを提案する。


# 5. バハムート残価クレジット

バハムートの契約条件は以下。

**バハムート価格：10億ゴールド**

**月々の支払い：10万ゴールド**

**契約期間：3年間**

契約期間終了時には、成長したバハムートの価値を査定する。

バハムートの査定額と残りの金額を相殺する。

査定額が不足した場合、主人公が残額を負担する。

主人公が支払えない場合、

**地下送り**

となる。


# 6. 基本ゲームループ

ゲーム中は基本的に、

**ストーリー**

↓

**冒険者ギルドで討伐依頼を受ける**

↓

**魔物のいる場所へ移動**

↓

**魔物討伐**

↓

**冒険者ギルドへ帰還**

↓

**討伐報酬を獲得**

↓

**ローン返済**

↓

**次のストーリーへ**

という流れを繰り返す。


# 7. 主な討伐対象

プロトタイプでは以下を使用する。

### ゴブリン

序盤の敵。

ゲームシステムと討伐報酬のチュートリアルを兼ねる。


### オーク

ゴブリンより強い敵。

主人公とバハムートの関係が深まるイベントを入れる。


### その他

必要に応じて以下を使用する。

- ゴブリンリーダー
- オークキング
- ワイバーン
- ゴーレム
- 魔王軍兵士


# 8. 所持金システム

プレイヤーは「ゴールド」を所持する。

例：

**所持金：120,000 G**

魔物を討伐すると報酬を獲得する。

例：

**ゴブリン討伐報酬**

+30,000 G

ローン返済時には所持金からゴールドが減少する。

例：

**バハムート残価設定型契約**

今月のお支払い

-100,000 G


# 9. ローン返済

一定のストーリー進行ごとにローン返済イベントを発生させる。

返済額：

**100,000 G**

所持金が返済額以上の場合は自動的に支払う。

所持金が返済額未満の場合、

**BAD END A：支払い不能**

へ移行する。


# 10. バハムート査定額

ゲーム中の行動によってバハムートの最終査定額が変化するシステムを想定する。

プロトタイプ段階では複雑な育成システムを実装する必要はない。

内部変数として、

`bahamutValue`

を保持する。

討伐実績やイベントなどによって値を増加させる。

# 12. エンディング

最低5種類を実装する。


## NORMAL END

魔王を討伐。

バハムートの査定にも成功。

借金がなくなり主人公は自由になる。


## BAD END A

ローン返済に必要なゴールドが不足。

支払い不能。

主人公が地下送りになる。


## BAD END B

魔王討伐には成功。

しかし最終的なバハムート査定額が不足。

残債を支払えず地下送りになる。


## BAD END C

魔王との戦闘に敗北。

GAME OVER。


## GOOD END

魔王を倒さず共闘。

主人公、バハムート、魔王の3人で神様と戦う。

神様を倒し、バハムートの契約そのものを消滅させる。


# 13. GOOD END最終展開

主人公、バハムート、魔王が天空の神殿へ向かう。

神様と対峙。

神様が本性を現す。

最終決戦。

主人公がバハムートの契約書を破壊。

神様を撃破。

ローン契約そのものが消滅する。

エンディングでは、

**「ローン完済！」**

ではなく、

**「ローン契約そのものが消滅しました」**

と表示する。


# 14. プロトタイプの実装方針

最初から完成版を目指さない。

まず、

**最初からGOOD ENDまで実際にプレイできること**

を最優先する。

プロトタイプでは、

- セーブ／ロード
- 豪華なアニメーション
- 複雑な戦闘
- 複雑な育成
- 高度なエフェクト

などは必須としない。

一方で、

- キャラクター表示
- 背景表示
- 会話
- 選択肢
- 所持金
- 討伐報酬
- ローン返済
- バハムート査定
- ルート分岐
- エンディング

は実装する。


# 15. 開発上の重要事項

この作品では、

**「魔物を倒す → お金をもらう → 喜ぶ → ローン返済でほぼ消える」**

という流れそのものがギャグとなる。

したがって所持金の増減はプレイヤーにはっきり見せること。

例：

**討伐報酬**

+80,000 G

↓

**現在の所持金**

185,000 G

↓

神様：

「今月のお支払い日です♪」

↓

**バハムートローン**

-100,000 G

↓

**現在の所持金**

85,000 G

この落差をゲーム演出として強調する。


# 16. 開発時の優先順位

Codexは以下の順番で実装する。

1. ノベルゲーム基本画面
2. シナリオ表示システム
3. キャラクター立ち絵
4. 背景
5. 選択肢
6. 所持金
7. 討伐報酬
8. ローン返済
9. バハムート査定
10. ルート分岐
11. エンディング

まずはゲーム全体を最後まで通してプレイできる状態を作り、その後、演出や画像素材を追加して完成度を上げる。
